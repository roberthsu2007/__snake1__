# NEON_SNAKE

A neon-style Snake game built with Vite, React, Tailwind CSS, and Motion.

## Run Locally

**Prerequisites:** Node.js

1. Install dependencies:
   `npm install`
2. Run the app:
   `npm run dev`

## Build

- `npm run build`

## GitHub Pages

This repository is configured to deploy automatically via GitHub Actions on `main` pushes.
The site will be served from:

`https://roberthsu2007.github.io/__snake1__/`
